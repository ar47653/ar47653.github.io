The first activity I did was to test my firewall using the Gibson Research: ShieldsUP! since it I was curious if my internet was secure enough to pass. Thankfully their protocol did not get exposed to the public internet. Even though this is a basic level security test, its a quick and convenient way to check your firewall's integrity. This is a great tool for education and raising awareness for internet security. I can see more security check tools like this to become features for computers and smartphones as security becomes more important. Perhaps there will be a device in the feature that specializes in providing security itself instead of a security program/software.
