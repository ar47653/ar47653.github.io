Security

The first activity I did was to test my firewall using the Gibson Research: ShieldsUP! since it I was curious if my internet was secure enough to pass. Thankfully their protocol did not get exposed to the public internet. Even though this is a basic level security test, its a quick and convenient way to check your firewall's integrity. This is a great tool for education and raising awareness for internet security. I can see more security check tools like this to become features for computers and smartphones as security becomes more important. Perhaps there will be a device in the future that specializes in providing security itself instead of a security program/software. For the next activity, I researched password manager and multi-factor authentication. Password managers are a great tool to quickly update passwords while maintaining a strong level of password quality. I am guilty of using the same or similar password across multiple accounts and platforms, so this would be a good solution for me to create multiple new passwords while having them accessible with the manager so I won't forget them. I am quite familiar with the multi- factor authentication since many accounts require the users to use it for stronger security. The most common two-factor authentication seems to be password and email/mobile text verification code. For mobile phone applications I am seeing more biometric verification since recent phones can scan fingerprints. It was interesting to see the types of verifications categorized to knowledge, possession, inherent, and location. I feel that in the future, location and inherent type verifications could be verified automatically on top of knowledge and possession to get the maximum level of security.
