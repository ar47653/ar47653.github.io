CSS

For this session, I learned how CSS works and created an external style sheet, internal style sheet, and inline style sheet. Each type of style sheet has a level of priority, with inline being highest, internal second, and external being the least. This layering of style sheets make a lot of sense as it allows for a universal layout or style with a lot of flexibility and customizeability. Again the Github Editor has a very useful autofill feature and even displays the 'color chip' when choosing a color. Interestingly, when you type in a value for a style, it will appear white if it is not a valid option. When valid, the text turns brown. Thanks to the external style sheet, I was able to keep experimenting with different styles with minimal effort to update all the pages at once.
