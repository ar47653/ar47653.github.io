I mainly use Gmail for emails, but my first email that I made was with Yahoo Mail. For work I use Microsoft Outlook for email and email client service. It makes sense that email is still used today as the main communication method for many professional settings. It is a great way to keep track and archive any written text or media that has been sent or recieved by anyone. However, one weakness of email is security. There are many instances even in well established companies where private information gets accessed through malicious links or attachment within an email. It is interesting how social media evolved throughout the past decade or so. From more generic platforms like Facebook to gimmicky ones like Snapchat. I've used a lot of these social media apps and sites but now I just use Facebook, LinkedIn, and Instagram. I've never heard of the media honeycomb model, so that was interesting to learn about. Most of the mainstream social media platforms have stronger aspects of the honeycomb than the other. I use VoIP frequently for work to communicate with my coworkers on Microsoft Teams. It is very convenient as the call can be made both on PC and phone through the app. I've used the remote desktop during covid lockdowns when I had to work from home and had to access my desktop PC at work. The IT department also uses it to troubleshoot or make necessary changes to an employee's PC. Until doing the Chrome Remote Desktop research, I didn't know Google had their own proprietary remote desktop technology. It makes a lot of sense that there is a distinction between Chrome Remote Desktop and Remote Assistance. Chrome Remote Desktop is for a setup that is a permanent access to a remote computer while Remote Assistance is for two parties to temporarily access one another's computer to complete a service.
