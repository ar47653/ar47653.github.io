Networking

The first activity for networking that I did were the Tutorialpoint tutorials. When seeing all the layers and protocols to successfully join a network or the internet, I was unsurprised of the level of complexity but was still overwhelmed by the amount of different processes. The graph showing the user accessing the server from the client via the TCP/IP was especially helpful. The internet domain names were very interesting. I'll definitely be more mindful about the domain names of websites I visit from now on. The second activity I chose was researching license and support costs. For Windows, the license cost is $139. For support, Windows Extended Security Updates cost $30. It seems MacOS license is free since it comes with the hardware by default. Apple has a subscription service called AppleCare which ranges from $9.99 to $19.99 a month depending on the type of device. Linux license is open source so it is also free. It looks like there are several third party companies like Red Hat, Ubuntu, and Oracle that sells their support from around $300 to more than a $1000 a year subscription. It's interesting to see how each provider handles their license and support. I've owned Windows and Mac OS before, but never thought about the price for their support service. It might be worth looking into since there are more security risks now more than ever for these devices.
